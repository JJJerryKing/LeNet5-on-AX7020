# 神经网络实现思路

## 整体数据流

```text
图片BRAM
→ 按行读取
→ 补零
→ 卷积1 → ReLU → 池化1
→ 卷积2 → ReLU → 池化2
→ 卷积3
→ 全连接1
→ 全连接2
→ Argmax
→ 类别编号
```

## 1. `PL`

集成 `image_reader` 和 `LeNet_top`：

- 接收PS给出的启动、输出接收等控制信号。
- 从图片BRAM读取输入。
- 将最终分类编号和完成信号提供给PS。

## 2. `image_reader`

按行读取图片：

- 收到启动信号后，从BRAM连续读取28个像素。
- 将28个像素保存在一行缓冲中。
- 一行读取完成后，通过 valid/ready 将整行发送给 `LeNet_top`。
- 当前行被接收后，再读取下一行。
- 完成28行后回到等待状态。

## 3. 输入补零

`LeNet_top` 将原始 `28×28` 图片转换成 `32×32`：

- 开始发送两行全零。
- 每个原始图像行左右各补两个零。
- 最后发送两行全零。
- 输出仍然以一次一整行的形式送入卷积1。

## 4. `line_loader_plus`：卷积层

卷积1、卷积2和卷积3共用这一结构：

- 一次接收所有输入通道的一整行像素。
- 每个输入通道维护5行缓存，对应 `5×5` 卷积核高度。
- 收满5行后，从每个输入通道中取出当前 `5×5` 窗口。
- 输入通道之间并行卷积，每个输入通道对应一个MAC。
- 将所有输入通道的MAC结果相加，再加偏置。
- 按输出通道顺序依次读取权重并计算。
- 收集完所有输出通道后，一次输出当前位置的全部通道像素。
- 行缓存窗口右移一个像素，继续计算下一个位置。
- 一行计算完成后接收下一行，行缓存整体向上移动。

三个卷积层分别实现：

```text
卷积1：32×32×1  → 28×28×6
卷积2：14×14×6  → 10×10×16
卷积3： 5×5×16  →  1×1×120
```

## 5. `mac`

完成一个输入通道内的点积：

- 接收一个 `5×5` 像素窗口和对应的 `5×5` 权重。
- 每周期并行计算一组乘法。
- 使用加法树计算当前组部分和。
- 多周期累加所有部分和。
- 输出该输入通道对当前输出通道的卷积结果。

## 6. `relu_plus`

所有通道同时进行ReLU：

- 一次接收当前位置的全部通道像素。
- 正数保持不变。
- 负数变为零。
- 下一周期输出处理后的全部通道像素。

## 7. `average_pooling` / `AverPooling`

完成 `2×2`、步长为2的平均池化：

- 每个通道配置一个 `AverPooling`，所有通道并行。
- 偶数行按两个相邻像素一组保存部分和。
- 下一奇数行再计算下面两个像素之和。
- 四个像素相加后除以4并舍入。
- 一次输出所有通道在同一池化位置的结果。

两级池化分别实现：

```text
池化1：28×28×6  → 14×14×6
池化2：10×10×16 →  5×5×16
```

## 8. `Line_Cache2` / `Line_Out_Cache`

将逐位置输出重新拼成整行：

- 上游每次输出同一位置的所有通道像素。
- 每个通道分别收集一整行像素。
- 所有通道都收满一行后，一次输出所有输入通道的完整行。
- 用于适配下一层卷积的整行输入接口。

## 9. `fullconnect`

一次接收完整输入向量：

- 保存卷积3或上一全连接层的全部输出。
- 按输出神经元顺序依次读取权重和偏置。
- 使用一个MAC完成当前输出神经元的点积。
- 对结果进行偏置、缩放和移位。
- 保存每个输出神经元的结果。
- 全部神经元计算完成后，一次输出完整结果向量。

两级全连接分别实现：

```text
全连接1：120 → 84
全连接2： 84 → 10
```

## 10. 权重和偏置ROM

- 每层权重和偏置保存在独立ROM中。
- 卷积层按输出通道顺序读取。
- 全连接层按输出神经元顺序读取。
- 当前地址对应当前正在计算的输出通道或神经元。

## 11. `argmax`

从10个分类分数中选择最大值：

- 输入有效时保存10个分数。
- 每周期比较一个分数。
- 保存当前最大值及其类别编号。
- 比较完成后输出最大值对应的类别编号。
- `O_data_valid` 保持有效，直到下游接收。

## 12. valid/ready握手

模块之间统一使用 valid/ready 握手，只有 `valid && ready` 同时成立时，数据才正式传递。
