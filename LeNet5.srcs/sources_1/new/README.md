# 神经网络实现思路

## 整体数据流

```text
DDR中的RGB888图片及宽高
→ AXI Master读取 → 灰度化 → 缩放到28×28 → 按行输出
→ 补零
→ 卷积1 → ReLU → 池化1
→ 卷积2 → ReLU → 池化2
→ 卷积3
→ 全连接1
→ 全连接2
→ Argmax
→ 类别编号
```

## 1. `PL`

集成 `preprocessing` 和 `LeNet_top`：

- 接收PS给出的启动、输出接收等控制信号。
- 通过AXI Master从固定DDR读取参数和RGB图片，预处理后逐行送入网络。
- 将最终分类编号和完成信号提供给PS。

PS启动时及每帧结果确认后，通过控制GPIO通道1的bit1对计算模块进行低有效复位。该通道待机写 `0x02`、启动写 `0x03`、复位写 `0x00`；复位保持10μs后释放并等待就绪，随后回传类别。复位覆盖预处理及LeNet，控制GPIO和AXI互连继续使用系统复位。

## 2. `preprocessing`

替代原 `image_reader` 的图像输入功能：

- 接受整帧启动请求后，实例化的HLS `resize_and_gray` IP通过AXI Master读取DDR。
- 固定基址为 `0x10000000`；前16字节为参数头：宽度和高度均为32位无符号数，分别位于偏移0、4，偏移8、12保留并写0；RGB数据从偏移16开始，按R、G、B逐字节紧密存放。
- 使用HLS视频库先灰度化，再通过 `hls::Resize` 缩放到 `28×28`。
- 每次通过AXIS交付一行28个像素，各像素占13位；AXIS为368位，低364位连接 `LeNet_top`。
- 封装同时等待HLS完成和28次行握手全部完成，再恢复整帧输入ready。

## 3. 输入补零

`LeNet_top` 将预处理后的 `28×28` 灰度图片补零成 `32×32`：

- 开始发送两行全零。
- 每个原始图像行左右各补两个零。
- 最后发送两行全零。
- 输出仍然以一次一整行的形式送入卷积1。

## 4. `line_loader_plus`：卷积层

卷积1、卷积2和卷积3共用这一结构：

- 一次接收所有输入通道的一整行像素。
- 每个输入通道维护5行缓存，对应 `5×5` 卷积核高度。
- 收满5行后，从每个输入通道中取出当前 `5×5` 窗口。
- 输入通道之间并行卷积，每个输入通道对应一个MAC。
- 将所有输入通道的MAC结果相加，再加偏置。
- 按输出通道顺序依次读取权重并计算。
- 收集完所有输出通道后，一次输出当前位置的全部通道像素。
- 行缓存窗口右移一个像素，继续计算下一个位置。
- 一行计算完成后接收下一行，行缓存整体向上移动。

三个卷积层分别实现：

```text
卷积1：32×32×1  → 28×28×6
卷积2：14×14×6  → 10×10×16
卷积3： 5×5×16  →  1×1×120
```

## 5. `mac`

完成一个输入通道内的点积：

- 接收一个 `5×5` 像素窗口和对应的 `5×5` 权重。
- 每周期并行计算一组乘法。
- 使用加法树计算当前组部分和。
- 多周期累加所有部分和。
- 输出该输入通道对当前输出通道的卷积结果。

## 6. `relu_plus`

所有通道同时进行ReLU：

- 一次接收当前位置的全部通道像素。
- 正数保持不变。
- 负数变为零。
- 下一周期输出处理后的全部通道像素。

## 7. `average_pooling` / `AverPooling`

完成 `2×2`、步长为2的平均池化：

- 每个通道配置一个 `AverPooling`，所有通道并行。
- 偶数行按两个相邻像素一组保存部分和。
- 下一奇数行再计算下面两个像素之和。
- 四个像素相加后除以4并舍入。
- 一次输出所有通道在同一池化位置的结果。

两级池化分别实现：

```text
池化1：28×28×6  → 14×14×6
池化2：10×10×16 →  5×5×16
```

## 8. `Line_Cache2` / `Line_Out_Cache`

将逐位置输出重新拼成整行：

- 上游每次输出同一位置的所有通道像素。
- 每个通道分别收集一整行像素。
- 所有通道都收满一行后，一次输出所有输入通道的完整行。
- 用于适配下一层卷积的整行输入接口。

## 9. `fullconnect`

一次接收完整输入向量：

- 保存卷积3或上一全连接层的全部输出。
- 按输出神经元顺序依次读取权重和偏置。
- 使用一个MAC完成当前输出神经元的点积。
- 对结果进行偏置、缩放和移位。
- 保存每个输出神经元的结果。
- 全部神经元计算完成后，一次输出完整结果向量。

两级全连接分别实现：

```text
全连接1：120 → 84
全连接2： 84 → 10
```

## 10. 权重和偏置ROM

- 每层权重和偏置保存在独立ROM中。
- 卷积层按输出通道顺序读取。
- 全连接层按输出神经元顺序读取。
- 当前地址对应当前正在计算的输出通道或神经元。

## 11. `argmax`

从10个分类分数中选择最大值：

- 输入有效时保存10个分数。
- 每周期比较一个分数。
- 保存当前最大值及其类别编号。
- 比较完成后输出最大值对应的类别编号。
- `O_data_valid` 保持有效，直到下游接收。

## 12. valid/ready握手

模块之间统一使用 valid/ready 握手，只有 `valid && ready` 同时成立时，数据才正式传递。

- PL对外的 `I_data_valid/I_data_ready` 表示整帧启动握手。
- `preprocessing` 与 `LeNet_top` 之间的握手每次传递一行，一帧共28行。
- PL对外的 `O_data_valid/O_data_ready` 表示最终分类结果的确认，与内部行握手分开。
